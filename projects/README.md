# Project Repository Index

The project section of the portfolio links to five dedicated repositories. Each repository contains project-specific documentation and the available files.

1. [NULL Motherboard](https://github.com/MrNullbyte01/NULL-Motherboard) — Raspberry Pi Zero 2 W carrier-board design in KiCad 10; design in progress. The old Front Panel PCB is preserved only as an archive.
2. [Cisco Networking Labs](https://github.com/MrNullbyte01/Cisco-Networking-Labs) — Packet Tracer lab files, topology screenshots, and lab catalogue.
3. [Raspberry Pi Cyberdeck](https://github.com/MrNullbyte01/Raspberry-Pi-Cyberdeck) — Cyberdeck reference research and build plan, inspired by Tommi Laukkanen's Cyberdore. Personal build evidence is still pending.
4. [BlackBerry Passport Revival](https://github.com/MrNullbyte01/BlackBerry-Passport-Revival) — device-revival documentation and software archive inventory. Third-party app packages are not mirrored until redistribution rights are verified.
5. [CTF Writeups](https://github.com/MrNullbyte01/CTF-Writeups) — CTF-related notes and technical study PDFs.

Project status is described conservatively. A planned or documented project is not presented as fabricated, assembled, or tested unless evidence supports that claim.
